# Деплой ШефДом!

Деплоит **только пользователь**, через Render Dashboard. Агент никогда не деплоит сам.

## Перед деплоем (после Блока 14)

1. Зайти в приложение → Настройки → «Скачать backup (JSON)»
2. Сохранить файл в iCloud / Файлы

На Блоке 1 backup ещё нет — пропускаем этот шаг.

## Деплой

1. Render Dashboard → сервис `chefdom` → вкладка **Manual Deploy**
2. Выбрать ветку `main` → **Deploy latest commit**
3. Дождаться зелёного статуса (3–5 минут на Free plan)

## Проверка после деплоя

Открыть в браузере:

```
https://chefdom.onrender.com/api/health
```

Ожидаемый ответ:

```json
{ "ok": true, "service": "chefdom", "ts": "2026-05-19T..." }
```

В Render → Logs увидеть строки:

```
[boot] старт ШефДом!
[boot] запуск миграций...
[migrate] применяю 001_users...
[migrate] 001_users — готово
[boot] запуск seed...
[seed] создан дефолтный пользователь: Семья (PIN 1234)
[boot] сервер слушает порт ...
```

При повторных деплоях миграции и seed увидят, что всё уже сделано, и пропустят шаги.

## Если деплой сломал приложение

1. Render Dashboard → **Deploys** → найти предыдущий успешный
2. Нажать **Rollback**
3. Через ~1 минуту приложение вернётся к рабочей версии
4. Данные в Neon **не затронуты** — они живут отдельно от кода

## Локальная разработка

```bash
cp .env.example .env
# подставить DATABASE_URL из Neon
npm install
npm run dev:server
```

Сервер: `http://localhost:3000/api/health`
