# 1. Общее понимание

**ШефДом!** — операционная система твоей кухни:
- Помнит всё в холодильнике, морозилке и кладовой
- Знает все рецепты
- Сам формирует список покупок из меню
- Сам списывает продукты при готовке (FEFO — сначала истекающие)
- Автоматически добавляет в покупки когда продукт ниже минимума
- Считает расходы и показывает где дешевле
- Подсказывает что приготовить из имеющегося

**Философия:** «Один раз настроил → каждый день работает само»

От тебя нужно только:
1. Сфоткать чек после магазина (30 сек)
2. Нажать «В инвентарь» (система сама предложит хранилище и срок)
3. Запланировать меню раз в неделю (5 мин)
4. Нажать «Готовить» когда готовишь

# 2. Первый вход

1. Открываешь сайт → экран «Введите PIN»
2. Вводишь 4-значный PIN → «Войти»
3. PIN по умолчанию: `1234` — **сразу смени в Настройках!**

**Защита:** 5 неправильных попыток → блокировка на 30 минут.

# 3. Главная страница

Сверху вниз:

**Приветствие** — «Доброе утро/день/вечер, Семья» + дата.

**Алерт «Истекает»** (жёлтый) — продукты с истекающим сроком (3 дня). Кнопка «Что приготовить?» ведёт к рецептам с этими продуктами.

**Алерт «Давно лежит»** (серый) — продукты без срока, которые лежат >30 дней.

**Блюдо дня** — фото из меню (завтрак/обед/ужин по времени суток).

**Карточки:** «Что приготовить?», «Список покупок» (с счётчиком), «Заготовки».

**«Любимое в этом месяце»** — рецепт, готовленный 2+ раза.

**«Недавно готовила»** — последние 5 блюд (свайп).

**Меню недели** — 7 кружков (Пн-Вс), тап → переход в Меню.

# 4. Рецепты

## Список
- Поиск, фильтры: Категория / Кухня / Сложность
- Карточки с фото, подгрузка по 20 штук
- Категории нормализованы: «Десерт»/«десерт»/«Десерты» = один чип **«Десерты»**

## Импорт по ссылке (самый быстрый!)
1. Скопируй URL рецепта (russianfood.com, povarenok.ru, allrecipes.com)
2. «Импорт по ссылке» → вставь → «Импортировать»
3. 5-10 сек → рецепт с фото, ингредиентами, шагами, КБЖУ

## Импорт с YouTube
1. Скопируй URL видео YouTube
2. «YouTube» → вставь → «Импортировать»
3. AI (Gemini) извлекает рецепт из субтитров:
   - Название, ингредиенты с количеством
   - **Шаги реконструируются из речи автора** (даже если нет явного списка)
   - Категория назначается автоматически

## Импорт раздела (массовый)
URL страницы со списком рецептов → «Запустить» → job работает в фоне.

## Добавить вручную
Форма: название, фото (URL), порции, время, категория/кухня/сложность, ингредиенты (кол-во + ед. + название + группа), шаги (инструкция + фото + таймер).

## Страница рецепта
- Фото, КБЖУ (ккал/белки/жиры/углеводы + % дневной нормы)
- Множитель порций ×1/×2/×4 (количества пересчитываются)
- «Чем заменить» — варианты замены ингредиентов
- Таймер на шагах (обратный отсчёт, уведомление по окончании)
- **Wake Lock** — экран не гаснет во время готовки

## Кнопка «Готовить сейчас»
1. Подтверждение → система:
   - Списывает ингредиенты из инвентаря (FEFO — сначала истекающие)
   - Чего нет → автоматически в Покупки
   - Если продукт упал ниже минимума → тоже в Покупки
   - Создаёт готовое блюдо в Заготовках (с порциями)
   - Записывает в Историю готовки
2. Сообщение: «Списано 6 из 8. 2 недостающих добавлено в покупки.»

# 5. Меню недели

- Навигация ← → (недели)
- Таблица 7 дней × 3 слота (Завтрак/Обед/Ужин)
- [+] в ячейке → поиск рецептов → тап = добавлено
- Несколько блюд в слоте (комплексный обед)
- ✕ удаляет блюдо

**Кнопка «В покупки →»:**
- Собирает ВСЕ ингредиенты всех рецептов недели
- Дедуплицирует (молоко в 5 рецептах = одна строка с суммой)
- Не добавляет если уже в покупках

**Умные подсказки:** кнопка «Подсказки» показывает:
- Рецепты с истекающими ингредиентами (приоритет!)
- Давно не готовили (разнообразие)
- Ещё не пробовали
- Высокая доступность ингредиентов (>70% есть дома)

# 6. Покупки

## Три источника:
1. **Из Меню** — кнопка «В покупки»
2. **Из Готовки** — недостающие ингредиенты + minQuantity
3. **Вручную** — кнопка [+]

## В магазине:
- Чекбоксы: отметил = купил
- **«Всё купленное → в инвентарь»:**
  1. Отмечаешь товары ✓
  2. Нажимаешь кнопку «В инвентарь»
  3. Система показывает превью с авто-раскладкой:
     - Крупы/макароны → Кладовая
     - Замороженное → Морозилка
     - Остальное → Холодильник
  4. Можешь поменять (тап по иконке)
  5. Подтверждаешь → товары в инвентаре + купленные очищаются

## После магазина:
- «Очистить купленные» — удалит отмеченные

# 7. Инвентарь

## Три хранилища:
- 🧊 **Холодильник** — молочка, овощи, мясо
- ❄️ **Морозилка** — долгое хранение
- 🏠 **Кладовая** — крупы, специи, консервы

## Карточка продукта:
- Название + количество + единица
- Срок годности (красный если <3 дней)
- **Мин. остаток** — метка `(мин: X)` если задан минимум
- Кнопки: редактировать, удалить

## Добавить вручную [+]:
- Название, количество, единица, хранилище, срок годности
- **Мин. остаток (авто-докупка)** — когда кол-во ниже, автоматически в покупки

## Заполняется автоматически:
- Из чеков → «В инвентарь» (с авто-подстановкой хранилища и срока)
- Из покупок → «Всё купленное → в инвентарь»
- Из готовки → готовое блюдо в Заготовки

## Уходит автоматически:
- При «Готовить» — FEFO (First Expire, First Out)
- Если упало ниже minQuantity → автоматически в Покупки

# 8. Заготовки

## Четыре вкладки:

### Готовые блюда (после «Готовить»)
- Название, порции, срок
- **Кнопка «Съесть»** — списывает 1 порцию. При 0 — блюдо удаляется.
- Корзина — удаляет блюдо целиком

### ❄️ Заморозка
- Бульоны, котлеты, ягоды, тесто, **выпечка, десерты**
- **Авто-подсказка срока:** вводишь «Чизкейк» → система предложит «годен до» через 3 мес
- Поддерживаются: пироги (4 мес), торты (3), кексы (4), мороженое (4), тесто (3-6), эклеры (2) и ещё ~40 позиций

### 🫙 Консервация
- Варенья, соленья, маринады

### 📦 Открытые продукты
- Начатые банки, вскрытые упаковки

**Важно:** заготовки учитываются в «Что приготовить» как доступные ингредиенты!

# 9. Чеки

## Список чеков:
- «Сфотографировать чек» (камера)
- «Добавить вручную»

## Сфотографировать:
1. Камера → фото → «Использовать»
2. OCR обрабатывает → парсер извлекает позиции (5-15 сек)
3. Поддержка: ALDI, Albert Heijn, Jumbo, Lidl, Пятёрочка, Магнит + любые другие
4. Автоперевод: NL/DE/PL → русский

## Страница чека:
- Магазин, дата, валюта, итог
- **«В инвентарь»** (главная кнопка!):
  1. Открывается диалог
  2. Все товары с чекбоксами (✓ по умолчанию)
  3. **Авто-подстановка:**
     - Хранилище определяется по названию (крупы→кладовая и т.д.)
     - Срок годности из справочника (если есть совпадение)
  4. Можно поменять если не согласен
  5. «Добавить (N)» → в инвентарь за один клик
- «Добавить позицию вручную»
- **«Перепарсить»** — перераспознать из сохранённого OCR-текста (видна только если чек создан через фото)
- «Сырой текст OCR» — для отладки

## Редактирование позиций:
- ✏️ → инлайн-форма → ✓

# 10. Аналитика

## Вкладка «Готовка»
- Период: Неделя / Месяц / 3 месяца
- Расход продуктов (топ-10)
- Топ-5 рецептов

## Вкладка «Расходы»
- Период: Этот месяц / Прошлый / Год
- Итог: сумма + кол-во чеков
- По магазинам (с суммами)
- Чаще всего покупали (топ-15 с ценами)
- По месяцам (годовой отчёт)

## Вкладка «Где дешевле» (НОВОЕ!)
- Показывает товары, купленные в 2+ магазинах
- Для каждого: средняя и мин. цена по магазинам
- Зелёная метка ✓ на самом дешёвом
- Значок «экономия X.XX» — разница между дорогим и дешёвым
- Сортировка по потенциальной экономии (самое полезное сверху)

---

# 11. Что приготовить?

## Как работает:
1. Берёт 100 последних рецептов
2. Для каждого считает «X из Y ингредиентов есть»
3. Умный матчинг: точное → подстрочное → стемминг
4. **Заготовки тоже учитываются!**
5. Сортирует: истекающие → по % имеющихся

## Фильтры:
- **🟢 Все** — с подсчётом «X из Y есть»
- **🟡 Спасти истекающее** — рецепты с истекающими продуктами
- **✓ Всё есть** — готовь прямо сейчас
- **➕ Докупить 1–2** — почти всё есть

# 12. Продукты (справочник)

- Каталог всех купленных товаров (название, бренд, последняя цена)
- Заполняется автоматически из чеков
- Поиск по названию
- Поиск по штрих-коду (камера → Open Food Facts → перевод)
- **Кнопка «Очистить»** требует подтверждения (защита от случайного удаления)

# 13. Настройки

- **Сменить PIN** — текущий + новый дважды (все сессии сбрасываются)
- **Валюта:** EUR (€) или RUB (₽)
- **Пересчитать КБЖУ** — обновит по справочнику USDA (batch по 10, быстрее)
- **Резервная копия:**
  - Экспорт: все данные в JSON (рецепты, инвентарь, чеки, история, заготовки, продукты)
  - Импорт: восстановление из JSON (удаляет только данные текущего пользователя)

# 14. Как всё связано

```
ПОНЕДЕЛЬНИК:
  Импорт рецептов → Меню → «В покупки» → список готов

ПОСЛЕ МАГАЗИНА:
  Фото чека → OCR → «В инвентарь» (авто хранилище + срок) → готово!

ГОТОВКА:
  Рецепт → «Готовить» → списание (FEFO) → готовое блюдо в Заготовках
  → недостающее в Покупки → minQuantity в Покупки

ЗАГОТОВКИ:
  Готовое блюдо → «Съесть» (−1 порция) → при 0 удаляется

АНАЛИТИКА:
  Чеки → расходы по магазинам → «Где дешевле» → экономия
```

# 16. Советы и лайфхаки

## Каждый день:
- Утром — блюдо дня + алерты
- Перед готовкой — «Готовить» (списание автоматическое)

## После магазина (всегда!):
1. Сразу фоткай чек
2. Сразу «В инвентарь» (система предложит хранилище)
3. Не откладывай!

## Раз в неделю:
- «Что приготовить?» → «Всё есть» → выбрать
- Меню → распланировать → «В покупки»

## Раз в месяц:
- Аналитика → Расходы
- «Где дешевле» → проверить экономию

## Что НЕ нужно делать:
- ❌ Не списывай вручную — система сама при «Готовить»
- ❌ Не вбивай товары руками — «В инвентарь» сама
- ❌ Не дедуплицируй покупки — автоматически
- ❌ Не выбирай хранилище каждый раз — система предложит

## Минимальный остаток (minQuantity):
- Задай при добавлении (например Молоко, мин: 1)
- Когда при готовке останется меньше → автоматически в покупки
- Больше не забудешь купить базовые продукты!

# 17. FAQ

**В: Как списать съеденную порцию готового блюда?**
О: Заготовки → Готовые → кнопка **«Съесть»** рядом с блюдом. Тап = −1 порция.

**В: Как задать минимальный остаток?**
О: Инвентарь → [+] → поле «Мин. остаток». Или редактируй существующий продукт.

**В: Где посмотреть в каком магазине дешевле?**
О: Аналитика → вкладка «Где дешевле». Нужны чеки из 2+ магазинов с одним товаром.

**В: Почему система сама предлагает хранилище?**
О: По ключевым словам: крупы/специи → кладовая, замороженное → морозилка, остальное → холодильник. Можно поменять.

**В: Как работает авто-подсказка срока?**
О: По справочнику ~300 продуктов. Если находит совпадение по названию → подставляет дату. Если нет — оставляет пустым.

**В: Чек плохо распознался?**
О: «Перепарсить» (если есть OCR-текст) или редактируй позиции вручную (✏️).

**В: YouTube не импортирует?**
О: Нужно видео с субтитрами. AI извлекает рецепт из речи автора, даже если шаги не оформлены списком.

**В: PIN по умолчанию?**
О: `1234`. Смени в Настройках!

**В: Данные одни на iPad и Samsung?**
О: Да — облачная база, одна для всех устройств.

**В: Сколько стоит?**
О: Бесплатно (Render Free + Neon Free + OCR.space + DeepL Free).

**В: Приложение засыпает?**
О: Нормально для Render Free — первый запрос ждёт 30-60 сек.
