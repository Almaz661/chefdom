# ШефДом — Полное руководство пользователя

## Вход в приложение

1. Откройте приложение в браузере
2. Введите PIN-код (по умолчанию: `1234`)
3. Нажмите «Войти»

---

## Навигация

**На десктопе** — боковое меню слева:
- Главная, Рецепты, Меню, Покупки, Инвентарь, Заготовки, Продукты, Чеки, Аналитика, Настройки

**На телефоне** — нижняя панель (5 главных):
- Главная, Рецепты, Меню, Покупки, Инвентарь
- Остальные разделы доступны через Главную страницу

---

## 1. Главная страница (`/`)

Что видишь:
- Приветствие по времени суток
- **Блюдо дня** — рецепт из меню на текущий приём пищи (завтрак/обед/ужин)
- **Истекающие продукты** — алерт с количеством товаров которые испортятся через 1-3 дня
- **Список покупок** — счётчик сколько товаров нужно купить
- **Недавно готовила** — последние 5 приготовленных блюд
- **Любимое в этом месяце** — самый популярный рецепт

Действия:
- Нажми на «Истекающие» → попадёшь в «Что приготовить» с рецептами из этих продуктов
- Нажми на блюдо дня → откроется рецепт

---

## 2. Рецепты (`/recipes`)

### Просмотр
- Список всех рецептов с фото, временем и категорией
- Фильтры: по категории, кухне, сложности
- Поиск по названию

### Добавить рецепт
1. Нажми кнопку **[+]** (правый верхний угол)
2. Два способа:
   - **По URL** — вставь ссылку с сайта рецептов → система сама распарсит и переведёт
   - **Вручную** — заполни название, ингредиенты, шаги

### Импорт раздела
1. На странице добавления → «Импорт раздела»
2. Вставь URL страницы со списком рецептов (например, раздел «Супы» на сайте)
3. Система загрузит все рецепты оттуда автоматически

### Страница рецепта (`/recipes/:id`)
- Фото, описание, КБЖУ
- Список ингредиентов (с подсветкой что есть в инвентаре)
- Пошаговая инструкция с таймерами
- Кнопка **«Готовить»** — списывает ингредиенты из инвентаря

### Кнопка «Готовить»
Что происходит при нажатии:
1. Из инвентаря списываются нужные ингредиенты (FEFO — сначала истекающие)
2. Если чего-то не хватает — автоматически добавляется в список покупок
3. Записывается в историю готовки
4. **Создаётся запись «Готовое блюдо»** в Заготовках с количеством порций (срок 3 дня)
5. Проверяется minQuantity — если продукт упал ниже минимума, добавляется в покупки

## 3. Меню недели (`/menu`)

### Заполнение меню
1. Видишь таблицу 7 дней × 3 приёма пищи (завтрак/обед/ужин)
2. Нажми **[+]** в любой ячейке
3. Откроется диалог выбора рецепта:
   - **Вверху — «Рекомендации»** (умные подсказки):
     - ⏰ Истекающие ингредиенты — «Используй курицу пока не испортилась»
     - 🔄 Давно не готовили — «Борщ — 21 день назад»
     - ✨ Новые рецепты — «Ещё не пробовали»
     - ✅ Доступные ингредиенты — «80% есть дома»
   - **Ниже — поиск** по всем рецептам
4. Нажми на рецепт → он добавится в слот
5. Удалить из слота — нажми [×] на карточке рецепта

### Навигация по неделям
- Стрелки [←] [→] — предыдущая/следующая неделя
- Сегодняшний день подсвечен

### Кнопка «В покупки →»
- Появляется когда меню не пустое
- Собирает ВСЕ ингредиенты из всех рецептов меню
- Дедуплицирует (не добавляет если уже есть в покупках)
- Суммирует количества (если рецепт стоит 2 раза — удваивает)

---

## 4. Покупки (`/shopping`)

### Добавить товар
- Внизу страницы поле ввода + кнопка [+]
- Пиши название → нажми [+] или Enter

### Отметить как купленное
- Нажми на **галочку** слева от товара → товар зачёркивается

### Кнопка «Всё в инвентарь»
- Появляется когда есть отмеченные (купленные) товары
- Нажми → все купленные товары переносятся в инвентарь автоматически:
  - StorageType определяется по ключевым словам (замороженное → морозилка, крупа → кладовая, остальное → холодильник)
  - ExpiryDate вычисляется из справочника сроков годности
- После переноса товары удаляются из списка покупок

### Очистить отмеченные
- Удаляет все отмеченные товары из списка БЕЗ переноса в инвентарь

### Прогресс-бар
- Показывает сколько из списка уже куплено (X из Y, N%)

---

## 5. Инвентарь (`/inventory`)

### Что здесь
- Все продукты которые сейчас есть дома
- Группировка: холодильник / морозилка / кладовая
- Срок годности с цветовой индикацией (красный = просрочен, жёлтый = скоро)

### Добавить продукт
1. Кнопка [+]
2. Заполни: название, количество, единица, тип хранения, срок годности
3. Срок годности подсказывается автоматически из справочника

### minQuantity (минимальное количество)
- Можно задать для любого продукта
- Когда продукт падает ниже этого значения (после готовки) — автоматически добавляется в покупки
- Пример: молоко minQuantity = 1 л → когда осталось 0.5 л → «Молоко 1 л» появится в покупках

### Пересчитать сроки
- Кнопка в настройках инвентаря
- Проставляет expiryDate всем продуктам у которых его нет (по справочнику shelf_life)

## 6. Заготовки (`/preserves`)

### 4 таба:

#### 👨‍🍳 Готовые блюда (первый таб)
- Автоматически появляются после нажатия «Готовить» на рецепте
- Показывает: название блюда, количество порций, дату приготовления, срок годности (3 дня)
- **Кнопка [-]** — съели 1 порцию (уменьшает счётчик, при 0 — удаляет)
- Алерт если блюдо скоро испортится

#### ❄️ Заморозка
- Котлеты, фарш, ягоды — всё что в морозилке
- Поле «Порции» — можно отслеживать сколько осталось
- **Авто-подсказка срока** — при вводе названия система ищет в справочнике и подставляет дату «хранить до»
- Кнопка [-] — списать порцию

#### 🫙 Консервация
- Варенье, соленья, маринады
- Дата заготовки + срок годности

#### 🥒 Открытые
- Открытые банки/пачки с коротким сроком
- Дата открытия + годен до

### Секция «Скоро истекает»
- Вверху каждого таба
- Показывает товары с истекающим сроком (≤3 дня) — жёлтым
- Просроченные — красным

## 7. Чеки (`/receipts`)

### Сканировать чек
1. Нажми [+] → «Сфотографировать чек»
2. Сфоткай чек из магазина
3. OCR распознает текст → парсер извлечёт позиции и цены
4. Проверь результат, исправь ошибки если нужно

### Перенести чек в инвентарь
1. Открой чек → страница с позициями
2. Кнопка «В инвентарь» — переносит товары из чека в инвентарь
3. Для каждого товара авто-определяется storageType и expiryDate

---

## 8. Что приготовить (`/what-to-cook`)

- Показывает рецепты отсортированные по:
  1. Сколько ингредиентов из рецепта УЖЕ есть дома
  2. Есть ли истекающие ингредиенты (приоритет)
- Для каждого рецепта видно: X из Y ингредиентов есть, Z истекает
- Учитывает инвентарь + заготовки (замороженное тоже считается)

## Типичные сценарии использования

### Сценарий 1: Планирование недели
1. **Меню** → заполни слоты на неделю (используй рекомендации)
2. **Меню** → нажми «В покупки →» (ингредиенты добавятся в список)
3. **Покупки** → бери телефон в магазин, отмечай галочками что купила
4. **Покупки** → дома нажми «Всё в инвентарь»

### Сценарий 2: Пришла из магазина с чеком
1. **Чеки** → сфоткай чек
2. **Чеки** → проверь распознанные позиции
3. **Чек** → «В инвентарь» (всё автоматически разложится по местам)

### Сценарий 3: Что приготовить прямо сейчас
1. **Главная** → виджет «Истекает» или
2. **Что приготовить** → рецепты из того что есть дома
3. Выбери рецепт → нажми **«Готовить»**
4. Ингредиенты списались, блюдо появилось в **Заготовки → Готовые**

### Сценарий 4: Отслеживание порций
1. Приготовила борщ (6 порций) → в **Заготовки → Готовые** появится «Борщ · 6 порц.»
2. Съели обед → нажми **[-]** → стало 5 порций
3. Съели ужин → **[-]** → 4 порции
4. Через 3 дня если осталось — алерт «истекает сегодня»

### Сценарий 5: Автопокупки когда кончается
1. **Инвентарь** → на молоке поставь minQuantity = 1
2. Готовишь рецепт с молоком → списалось → осталось 0.3 л
3. В **Покупки** автоматически появится «Молоко 1 л»
