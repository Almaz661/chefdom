# Часть 1. ОБЩЕЕ ПОНИМАНИЕ

## Что такое ШефДом?

**ШефДом!** — это умный помощник на кухне, который:
- Помнит всё что лежит у тебя в холодильнике, морозилке и кладовой
- Знает все твои рецепты
- Сам формирует список покупок когда ты планируешь меню
- Сам списывает продукты когда ты готовишь
- Сам считает сколько ты тратишь на еду в месяц
- Подсказывает что приготовить из того что есть

Это **не книга рецептов**, а **операционная система твоей кухни**.

## Главная философия

> «Один раз настроил → каждый день работает само»

Тебе **не нужно** каждый раз руками вводить продукты или считать что закончилось. Система делает это сама. От тебя нужно только:

1. **Сфоткать чек** после магазина (30 секунд)
2. **Нажать «В инвентарь»** в чеке (30 секунд)
3. **Запланировать меню** раз в неделю (5 минут)
4. **Нажать «Готовить»** когда готовишь блюдо

Всё остальное приложение делает само.

# Часть 2. ПЕРВЫЙ ВХОД

## Как войти

1. Открываешь сайт в браузере (или приложение если установлено на телефон)
2. Видишь экран «Введите PIN»
3. Вводишь свой 4-значный PIN-код
4. Нажимаешь «Войти»
5. Попадаешь на Главную страницу

## Защита от угадывания

Если 5 раз введёшь неправильный PIN — система заблокирует вход с твоего устройства на 30 минут. Это защита от того чтобы кто-то посторонний угадал PIN.

PIN по умолчанию для новой установки — `1234`. **После первого входа обязательно смени** в Настройках!

# Часть 3. ГЛАВНАЯ СТРАНИЦА (Dashboard)

Это первое что ты видишь после входа. Сверху вниз:

## 3.1 Приветствие

«Доброе утро, Семья» (или Добрый день / Добрый вечер / Доброй ночи) + сегодняшняя дата прописью «Воскресенье, 24 мая».

Логика:
- 5:00–11:00 → «Доброе утро»
- 11:00–17:00 → «Добрый день»
- 17:00–22:00 → «Добрый вечер»
- 22:00–5:00 → «Доброй ночи»

## 3.2 Алерт «Истекает» (жёлтый блок)

Появляется если в инвентаре или заготовках есть продукты со сроком годности в ближайшие 3 дня.

Что показывает:
- Иконка ⚠️ оранжевого цвета
- Текст: «3 продукта истекают в ближайшие 3 дня»
- Список названий через точку: «Молоко · Куриные крылышки · Йогурт»
- Кнопка «Что приготовить?» → переход к рецептам которые используют эти продукты

Если нет истекающих — блок просто не показывается.

## 3.3 Алерт «Давно лежит» (серый блок)

Появляется если в инвентаре есть продукты которые лежат больше 30 дней.

Зачем нужно: напоминание чтобы использовать «забытые» продукты.

## 3.4 Блюдо дня (большая карточка с фото)

Большое фото блюда + подпись «ЗАВТРАК» / «ОБЕД» / «УЖИН» (зависит от времени).

Логика выбора:
- Утром (5:00–11:00) → берёт ЗАВТРАК из меню на сегодня
- Днём (11:00–17:00) → берёт ОБЕД
- Вечером (17:00+) → берёт УЖИН

Если на сегодня меню не заполнено — серая карточка с приглашением открыть меню недели.

## 3.5 Две большие карточки рядом

**«Что приготовить?»** — иконка шапки шефа, переход к подбору рецептов.

**«Список покупок»** — иконка корзины, счётчик: «5 позиций · 2 куплено».

## 3.6 Карточка «Заготовки»

Иконка снежинки, ведёт в раздел Заготовки.

## 3.7 «Любимое в этом месяце»

Показывается если готовила один рецепт 2+ раза за месяц. Карточка с 🏆 и кликабельным названием.

## 3.8 «Недавно готовила»

Горизонтальная полоса с карточками последних 5 приготовленных блюд (свайп влево/вправо).

## 3.9 Меню недели (полоса с кружками)

7 кружков (Пн-Вс):
- Пустой кружок = на этот день ничего не запланировано
- Кружок с цифрой = столько блюд запланировано
- Сегодняшний день подсвечен голубым

Тап на любой день → переход на страницу Меню.

# Часть 4. РЕЦЕПТЫ

## 4.1 Список рецептов

Вверху:
- Кнопки: «Импорт по ссылке», «Импорт раздела», «Добавить»
- Поисковая строка
- Фильтры: Категория, Кухня, Сложность

Список — карточки с фото, названием, временем готовки. Подгружается по 20 штук.

## 4.2 Импорт по ссылке (самый быстрый способ!)

1. Найди в браузере любой рецепт (russianfood.com, povarenok.ru, allrecipes.com)
2. Скопируй ссылку
3. На странице Рецепты → «Импорт по ссылке» → вставь URL → «Импортировать»
4. Подожди 5-10 секунд
5. Готово! Рецепт со всеми данными:
   - Название, фото, время приготовления, порции
   - Все ингредиенты с количеством
   - Все шаги с инструкциями
   - КБЖУ (рассчитывается автоматически по справочнику USDA)

## 4.3 Импорт раздела (массовый)

Когда хочешь импортировать сразу много рецептов с одного сайта (например все «Супы»):

1. «Импорт раздела» → URL страницы со списком рецептов → «Запустить»
2. Job работает в фоне
3. Возвращаешься позже → видишь сколько добавлено

## 4.4 Добавить вручную

Форма из 5 секций:

### Секция 1: ОСНОВНОЕ
- **Название** (обязательное *)
- **Описание** (необязательно)
- **Ссылка на фото** (URL — увидишь превью)

### Секция 2: ВРЕМЯ И ПОРЦИИ
- Порций (по умолчанию 4)
- Подготовка, мин
- Готовка, мин
- Всего, мин (если пусто — авто-сумма)
- Калории на порцию

### Секция 3: КАТЕГОРИЯ, КУХНЯ, СЛОЖНОСТЬ

Все три — выпадающие списки!

**Категория:** Завтрак / Обед / Ужин / Закуска / Десерт / Напиток / Соус / Гарнир

**Кухня:** Русская / Украинская / Итальянская / Французская / Японская / Китайская / Грузинская / Средиземноморская / Прочая

**Сложность:** Легко / Средне / Сложно

### Секция 4: ИНГРЕДИЕНТЫ
- Кол-во (можно с запятой: «1,5»)
- Ед. (л, кг, шт, мл, г, ст.л., ч.л.)
- Название (обязательное)
- Группа (необязательно)
- Кнопки: ↑ ↓ 🗑️
- Кнопка «+ Добавить»

Подсказка: «Кол-во можно с запятой: 1,5. Оставь пустым — будет «по вкусу»».

### Секция 5: ШАГИ
- Большие пронумерованные блоки
- Текст инструкции
- Ссылка на фото шага (необязательно)
- Таймер, мин (если ввести → на странице рецепта появится кнопка таймера)

## 4.5 Страница конкретного рецепта

### Hero (фото)
Большое фото 16:9. Если нет — серый фон с шапкой шефа.

### Заголовок и кнопки управления
- Название
- Подзаголовок: Кухня · Категория · Сложность
- Источник (если импортирован)
- Кнопки: ✏️ редактировать, 🗑️ удалить, 🍳 готовить (мини)

### Факты в строку
- 🕐 «45 мин»
- 👥 «4 порции»
- 🔥 «320 ккал/порц.»
- 🌙 «Экран не гаснет» (Wake Lock)

### Карточка КБЖУ
4 столбца: Ккал, Белки, Жиры, Углеводы. Под каждым — % от дневной нормы.

### Описание
Курсивом, в одну колонку.

### Секция «Ингредиенты»
- Переключатель ×1 / ×2 / ×4 (множитель порций)
- Все количества пересчитываются автоматически
- Группировка (если указаны группы)
- Иконка ↻ «Чем заменить» — показывает варианты замены

### Секция «Шаги»
- Пронумерованные блоки с большими цифрами
- Под текстом — фото шага (если есть)
- Кнопка «Запустить таймер на 30 мин» (если у шага задан таймер):
  - Нажимаешь → начинается обратный отсчёт
  - Сворачиваешь приложение → таймер продолжает
  - Когда время вышло → уведомление + звук

### Sticky кнопка «Готовить сейчас»

Большая голубая кнопка прилипает к низу экрана.

При нажатии:
1. Подтверждение: «Готовить? Ингредиенты будут списаны из инвентаря.»
2. Система:
   - Загружает все ингредиенты рецепта
   - Загружает весь твой инвентарь
   - **Умный поиск**: точное совпадение → подстрочное → двуязычное → по корням
   - Списывает найденное (FEFO — сначала истекающие)
   - Чего нет → автоматически в Покупки
3. Записывает факт готовки в Историю
4. Сообщение: «Списано 6 из 8. 2 недостающих добавлено в покупки.»

# Часть 5. МЕНЮ НЕДЕЛИ

## 5.1 Что видишь
- Заголовок + навигация ← → (предыдущая / следующая неделя)
- Дата диапазона
- Таблица 7 колонок × 3 строки (Завтрак, Обед, Ужин)

На десктопе/iPad — таблица. На телефоне — вертикальный список дней.

## 5.2 Как добавить блюдо

1. Нажимаешь [+] в нужной ячейке
2. Открывается диалог с поиском рецептов
3. Тапаешь на нужный → он появляется в ячейке

## 5.3 Несколько блюд в слоте (комплексный обед)

Можно добавить несколько блюд в одну ячейку (суп + второе + салат):
1. Добавила «Борщ» в обед на Понедельник
2. Кнопка [+] остаётся видной (стала меньше но осталась)
3. Нажимаешь снова → добавляешь «Котлеты»
4. Снова [+] → «Салат»

## 5.4 Удалить блюдо
✕ на карточке блюда — мгновенное удаление.

## 5.5 Кнопка «В покупки →»

Большая голубая кнопка под таблицей.

Что делает:
1. Берёт ВСЕ рецепты этой недели
2. Собирает все их ингредиенты
3. **Дедуплицирует** — «молоко» в 5 рецептах = одна строка с суммой
4. Учитывает модификаторы — «Перец чёрный молотый» = «Перец»
5. Не добавляет если уже есть в покупках
6. Alert: «Добавлено 23 продукта в список покупок»

# Часть 6. ПОКУПКИ

## 6.1 Откуда берутся позиции (3 источника)

1. **Из Меню** — кнопка «В покупки» (ингредиенты всех рецептов недели)
2. **Из Готовки** — автоматически (недостающие ингредиенты)
3. **Вручную** — кнопка [+]

## 6.2 В магазине

Простой сценарий: отмечаешь чекбоксами что взяла.

Полный цикл:
1. Берёшь молоко с полки
2. Нажимаешь 🛒 «Купить и в инвентарь»
3. Выбираешь хранилище: 🧊 / ❄️ / 🏠
4. Молоко:
   - Помечается купленным (зачёркнуто)
   - Автоматически попадает в Инвентарь

## 6.3 После магазина
- Кнопка «Очистить купленные» — удалит все отмеченные
- Купленные через «Купить и в инвентарь» уже в инвентаре

## 6.4 Дедупликация
Система автоматически объединяет дубли (если одна позиция попала дважды).

# Часть 7. ИНВЕНТАРЬ

## 7.1 Структура

Три хранилища:
- 🧊 **Холодильник** — для молочки, овощей, мяса для готовки сегодня-завтра
- ❄️ **Морозилка** — для долгого хранения
- 🏠 **Кладовая** — крупы, специи, консервы

## 7.2 Карточка продукта
- Название
- Количество и единица
- 📅 «Годен до 27 мая» (красный если до 3 дней)
- Категория
- Кнопки: ✏️ редактировать, 🗑️ удалить

## 7.3 Добавить вручную (кнопка [+])

Поля:
- **Название** (обязательно)
- **Количество** (необязательно)
- **Единица** (л, кг, шт)
- **Где хранить** (3 варианта)
- **Годен до** (дата из календаря)
- **Категория** (необязательно)

## 7.4 Заполняется автоматически

- Из чеков → «В инвентарь» (массово)
- Из покупок → «Купить и в инвентарь»

## 7.5 Уходит автоматически

При нажатии «Готовить сейчас» — ингредиенты списываются по FEFO (сначала истекающие).

## 7.6 Алерты
- На главной: жёлтый алерт «Истекает в 3 дня»
- В Что приготовить: фильтр «🟡 Спасти истекающее»

# Часть 8. ЗАГОТОВКИ

## 8.1 Три типа

### ❄️ Заморозка
- Что замораживаешь (бульоны, котлеты, ягоды, тесто)
- Поля: название, кол-во, порции, дата заморозки, годен до
- **Авто-подсказка срока**: если введёшь «Куриные котлеты» — система предложит «годен до» через 4 месяца

### 🫙 Консервация
- Варенья, соленья, маринады
- Поля: название, кол-во, дата заготовки, годен до

### 📦 Открытые продукты
- Начатые банки, вскрытые упаковки
- Зачем: помнить когда открыла и сколько ещё годен

## 8.2 Связь с Что приготовить
Заготовки **тоже считаются доступными ингредиентами**! Замороженный бульон в заготовках = «бульон» в рецепте → система покажет что он есть.

# Часть 9. ЧЕКИ

## 9.1 Список чеков

Вверху:
- «Сфотографировать чек» (с иконкой камеры)
- «Добавить вручную (без фото)»

Карточки чеков:
- Логотип/название магазина
- Дата покупки + статус (черновик / финал)
- Сумма

## 9.2 Сфотографировать чек

1. Нажимаешь «Сфотографировать чек»
2. Открывается камера → фотографируешь
3. Подтверждаешь «Использовать фото»
4. Загрузка → OCR обрабатывает → парсер извлекает позиции
5. Через 5-15 секунд → страница чека готова

Поддерживаемые магазины: ALDI, Albert Heijn, Jumbo, Lidl + любые другие.

## 9.3 Страница чека

Шапка:
- Название магазина (кликабельно для редактирования)
- Дата (кликабельно)
- Валюта
- Итог по чеку

Кнопки:
- 🟦 **«В инвентарь»** (голубая, основная!)
- ➕ «Добавить позицию вручную»
- 🔄 «Перепарсить»

## 9.4 Кнопка «В инвентарь» (детально)

1. Нажимаешь голубую кнопку
2. Открывается диалог
3. Подсказка: «Выбери товары и укажи где хранить и до какого числа годен»
4. Кнопки сверху: «Выбрать все · Снять все»
5. Список позиций с чекбоксами (все отмечены ☑)
6. Для отмеченных:
   - **Где хранить**: 🧊 / ❄️ / 🏠
   - **Годен до**: дата
7. Снизу кнопка «Добавить (5)» — цифра показывает сколько отмечено
8. Нажимаешь → товары попадают в инвентарь
9. Подтверждение: «✓ Добавлено в инвентарь!»

## 9.5 Редактирование позиций

Если позиция распозналась плохо:
1. ✏️ карандаш → инлайн-форма
2. Меняешь название, цену
3. ✓ галочка → сохранилось

Если позиции нет:
- «Добавить позицию вручную» → форма

## 9.6 Сырой текст OCR (для отладки)

Внизу — сворачиваемый блок «Сырой текст OCR».
- Раскрываешь
- Видишь полный текст как его увидела OCR
- Кнопка «Скопировать»
- Можно прислать разработчику для настройки парсера
- После доработки → «Перепарсить» обновит позиции без нового фото

# Часть 10. АНАЛИТИКА

## 10.1 Вкладка «Готовка»

Период: Неделя / Месяц / 3 месяца

- **Расход продуктов** — топ-10 ингредиентов которые использовались чаще всего
- **Топ-5 рецептов** — что готовила больше всего

## 10.2 Вкладка «Расходы»

# Часть 11. ЧТО ПРИГОТОВИТЬ?

## 11.1 Как работает

Алгоритм:
1. Берёт топ-100 рецептов из базы
2. Для каждого считает «X из Y ингредиентов есть»
3. Использует **умный матчинг**:
   - Извлекает варианты имени из формата «Original (Перевод)»
   - Стемминг русских окончаний (куриные → курин)
   - Пословный матч (≥2 общих корня = совпадение)
4. **Заготовки тоже учитываются** как доступные продукты!
5. Сортирует: рецепты со скоропортящимися → по % имеющихся

## 11.2 Фильтры

**🟢 Все рецепты** — все с подсчётом «X из Y есть»

**🟡 Спасти истекающее** ⭐ (самый полезный!) — рецепты которые используют истекающие продукты. Готовь пока не пропали.

**✓ Всё есть** — где X = Y. Можно готовить прямо сейчас.

**➕ Докупить 1–2** — почти всё есть, нужно только 1-2 продукта.

## 11.3 Карточка рецепта
- Фото слева (квадрат)
- Название
- 🕐 «45 мин» · 👥 «4 порц.»
- Теги: «6 из 8 есть», «Использует 2 истекающ.»
- Тап → открывает страницу рецепта

# Часть 12. ПРОДУКТЫ (справочник)

## 12.1 Что это
Каталог всех товаров которые ты когда-либо покупала. Хранит название, бренд, последнюю цену.

## 12.2 Заполнение автоматическое
- При фото чека ALDI — товары попадают с ценами
- При сканировании штрих-кода — товар добавляется

## 12.3 Поиск по названию
Вводишь часть названия → видишь:
- Название (на русском)
- Бренд
- Последняя цена
- Когда обновлено

Зачем: «Сколько в прошлый раз стоил тот йогурт?»

## 12.4 Поиск по штрих-коду

1. Вкладка «По штрих-коду»
2. «Сканировать» → камера → наводишь на штрих-код
3. Система:
   - Шаг 1: ищет в локальной БД
   - Шаг 2: запрашивает Open Food Facts (мировая база)
   - Шаг 3: переводит NL/EN → RU (DeepL)
4. Сохраняет для следующих поисков

# Часть 16. СОВЕТЫ И ЛАЙФХАКИ

## 16.1 Каждый день
- **Утром** — открой приложение, посмотри блюдо дня и алерты
- **Перед готовкой** — нажимай «Готовить» сразу как начнёшь
- **Не забывай таймер** на шагах — приложение прозвонит

## 16.2 После магазина (всегда!)

1. **Сразу фоткай чек** — пока не потерялся
2. **Сразу нажимай «В инвентарь»** — пока помнишь куда положила
3. **Не откладывай!** — забудешь и инвентарь будет неточным

## 16.3 Раз в неделю (воскресенье вечер)
- Просмотри что осталось
- «Что приготовить?» → «✓ Всё есть» → выбери 3-4 рецепта
- «Меню» → распланируй
- «В покупки →» → список готов

## 16.4 Раз в месяц
- **Аналитика → Расходы (Прошлый месяц)** → куда ушли деньги
- **Аналитика → Готовка** → топ блюд

## 16.5 Раз в год (декабрь)
- **Аналитика → Расходы (Весь 2026)** → итоги года
- Сезонность по месяцам

## 16.6 Что НЕ нужно делать
- ❌ Не списывай продукты вручную — система сама при «Готовить»
- ❌ Не вбивай товары с чека руками — кнопка «В инвентарь» сама
- ❌ Не дедуплицируй покупки руками — автоматически
- ❌ Не указывай срок годности «навсегда» — лучше оставить пустым

## 16.7 Если что-то пошло не так

**OCR плохо распознал чек** → редактируй позиции вручную или копируй сырой текст для разработчика.

**«Готовить» ничего не списало** → проверь что названия в инвентаре похожи на ингредиенты рецепта.

**Список покупок дублируется** → удали лишнее вручную.

**Меню не обновляется на главной** → перезагрузи страницу.

**Приложение засыпает первый раз** → нормально для Render Free, ждёт 30-60 секунд.

# Часть 17. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

**В: Можно поделиться приложением?**
О: Можно сделать другую копию для другой семьи. Бесплатно (Render + Neon Free), 30 минут.

**В: Ошиблась с датой чека?**
О: Тап на дату → календарь → выбери правильную → ✓.

**В: Как удалить чек?**
О: 🗑️ справа сверху на странице чека. Подтверди. Продукты в инвентаре остаются.

**В: PIN по умолчанию?**
О: `1234`. Смени в Настройках сразу!

**В: iPad и Samsung — будут разные данные?**
О: Нет! Облачное приложение, одна база.

**В: Чек ALDI на голландском — увижу русский?**
О: Да! DeepL переводит. Формат: `Kippenvleugels (Куриные крылышки)`.

**В: Можно менять импортированные рецепты?**
О: Да! ✏️ редактирование. Источник сохраняется.

**В: Не импортируется по ссылке?**
О: Не все сайты используют JSON-LD. Добавь вручную.

**В: Меню на 2 недели вперёд?**
О: Да! Стрелки ← → переключают недели. Можно на 4+ недель.

**В: Удалить инвентарный продукт?**
О: 🗑️ рядом с продуктом.

**В: Что такое FEFO?**
О: First Expire, First Out — при готовке берёт скоропортящиеся первыми. Экономит еду.

**В: Ингредиент «по вкусу» (соль)?**
О: Оставь поле «Кол-во» пустым → отобразится «по вкусу».

**В: Своё фото блюда?**
О: Сейчас только URL. Загрузка с устройства — в планах.

**В: Сколько стоит?**
О: Бесплатно! Render Free + Neon Free + OCR.space (25k запросов/мес) + DeepL (500k символов/мес).
