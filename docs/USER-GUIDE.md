# 📖 ШефДом! — Инструкция по использованию

> Полное руководство для пользователя.
> Простым языком, без технического жаргона. По разделам.

---

## 🔑 1. Вход в приложение

При первом заходе ты увидишь экран ввода **PIN-кода**.
- PIN из 4 цифр.
- Если сервер «спит» (бесплатный план Render засыпает каждые 15 мин) — после первого ввода может появиться сообщение «Сервер просыпается, подожди 30 секунд». Это нормально.
- Если 5 раз введёшь неверный PIN — вход с твоего IP заблокируется на 30 минут (защита от взлома).

После входа сохраняется сессия на 30 дней — повторно вводить PIN не нужно.

## 🏠 2. Главная страница

Это твой ежедневный «дашборд». Сверху вниз:

### Приветствие
«Доброе утро / день / вечер / ночь, Семья» — меняется по времени суток.
Под ним — сегодняшняя дата.

### ⚠️ Алерт «Истекает скоро» (жёлтый)
Появляется если в инвентаре **или в заготовках** есть продукты со сроком ≤ 3 дней.
Покажет сколько штук и их названия (заготовки помечены «(заготовка)»).
Кнопка справа:
- если есть продукты из инвентаря → «Что приготовить?»
- если только заготовки → «Открыть»

### 🕐 Алерт «Лежит давно» (серый)
Если в инвентаре есть продукты добавленные больше 30 дней назад.
Кнопка «Открыть инвентарь».

### 🍳 Блюдо дня
Большая карточка с фото и кнопкой «Готовить сейчас».
- Если в меню недели на сегодня запланирован рецепт — он появится здесь автоматически (по времени суток выбирается завтрак / обед / ужин).
- Если ничего не запланировано — кнопка «Открыть меню недели».

### Карточки быстрого доступа
- **«Что приготовить?»** — поиск рецептов из имеющихся дома продуктов.
- **«Список покупок»** — счётчик «N позиций · M куплено».
- **«Заготовки»** ❄️ — переход в раздел заготовок одним тапом (на телефоне в нижнем меню её нет).

### 🏆 Любимое в этом месяце
Появляется если за месяц одно блюдо приготовлено ≥ 2 раз.

### Недавно готовила
Горизонтальный скролл с последними 5 приготовленными рецептами.
Кнопка «Вся история» → переход в `/history`.

### Меню недели (полоска)
7 кружочков Пн–Вс. Сегодняшний день выделен оранжевым.
Кнопка «Изменить» → переход в меню.

## 📚 3. Рецепты

Раздел `/recipes`. Тут хранятся все рецепты.

### Добавить рецепт
Кнопка **[+]** в правом верхнем углу. Три способа:

1. **Импорт по ссылке** 🔗
   Вставь URL любого кулинарного сайта — приложение само распарсит:
   название, фото, ингредиенты, шаги, время, КБЖУ.
   Поддерживаются schema.org/Recipe сайты (большинство популярных).

2. **Импорт раздела сайта** 📑
   Вставь URL раздела (например «Супы» с одного сайта) — приложение возьмёт все рецепты из раздела сразу.

3. **Создать вручную** ✏️
   Заполнить поля самой: название, фото, время, ингредиенты, шаги.

### Карточка рецепта
- Фото
- Название (серифом, как в кулинарной книге)
- Время приготовления, категория, кухня, сложность
- Калории на порцию

Поиск и фильтры — сверху страницы.

### Страница рецепта (открой любой рецепт)
- **Слайдер порций** — увеличь / уменьши, ингредиенты автоматически пересчитаются.
- **Список ингредиентов** с галочками. Можешь зачёркивать что уже использовала.
- **Замены ингредиентов** — кликни на ингредиент, появятся варианты замены (~480 готовых пар: «масло сливочное → масло подсолнечное» и т.д.).
- **Шаги готовки** — пронумерованные. У шагов есть кнопка таймера ⏱.
- **Кнопка «Готовить»** внизу — записывает в историю готовки и (опционально) списывает ингредиенты из инвентаря.
- **«Добавить в покупки»** — отправляет недостающие ингредиенты в список покупок.

## 📅 4. Меню недели

Раздел `/menu`. Календарь Пн–Вс × Завтрак / Обед / Ужин = 21 слот.

### Как использовать
1. Тапни на любой слот → откроется список рецептов → выбери.
2. Можешь перетаскивать рецепты между слотами.
3. Кнопка **«Очистить неделю»** — удаляет все слоты.
4. Кнопка **«Добавить в покупки»** — собирает все ингредиенты из меню недели в список покупок (с дедупликацией: одинаковые продукты объединяются).

### Что важно знать
- Дубли ингредиентов из разных рецептов автоматически объединяются (например «Соль» из 3 рецептов = одна позиция в покупках).
- В покупки записывается чистое имя без «по вкусу», «– опционально» и т.п.

## 🛒 5. Список покупок

Раздел `/shopping`. Список того что нужно купить.

### Что умеет
- Галочки — отметить «куплено».
- Кнопка **[+]** — добавить позицию вручную.
- Кнопка корзины — удалить позицию.
- Кнопка **«Очистить купленное»** — удалить все отмеченные позиции.
- Группировка по категориям (овощи, мясо, молочка и т.д. — определяется автоматически).

### Откуда попадают позиции
1. Из меню недели (кнопка «Добавить в покупки»).
2. Со страницы рецепта (кнопка «Добавить в покупки»).
3. Вручную через [+].

## 🧊 6. Инвентарь

Раздел `/inventory`. Что есть дома прямо сейчас.

### Три вкладки
- 🥕 **Холодильник** — свежие продукты
- ❄️ **Морозилка** — замороженное
- 📦 **Кладовая** — крупы, консервы, специи

### Как добавить продукт
**Способ 1: вручную** — кнопка **[+]**
- Название, количество, единица измерения, срок годности (опционально).

**Способ 2: через штрих-код** — кнопка сканера 📷
- Камера откроется, поднеси штрих-код товара.
- Если товар найден в каталоге Open Food Facts — название и упаковка подставятся сами.
- Если не найден — добавишь вручную.
- Выбираешь куда положить (холодильник / морозилка / кладовая).

### Что показано в карточке
- Название и количество
- Срок годности (если указан): «истекает завтра», «через 5 дн.», «просрочен» и т.д.
- Кнопка корзины — удалить.

### Группа «Заготовки» во вкладке Морозилка
Все заморозки из раздела `/preserves` показываются здесь автоматически:
- В отдельной группе сверху со снежинкой ❄️
- Со ссылкой «в раздел →» на страницу заготовок
- Удаление работает корректно — удалит и из заготовок тоже

### Алерт «Скоро истекает»
В каждой вкладке сверху — продукты со сроком ≤ 2 дней (жёлтый/красный фон).

## 🥶 7. Заготовки

Раздел `/preserves`. Подготовленное впрок.

### Три вкладки
- ❄️ **Заморозка** — котлеты, фарш, ягоды, бульоны
- 🫙 **Консервация** — варенье, соленья, маринады
- 🥒 **Открытые продукты** — открытые банки/пачки в холодильнике

### Чем отличается от Инвентаря?
- **Инвентарь** = что есть прямо сейчас (молоко, сырое мясо, овощи).
- **Заготовки** = специально подготовленное впрок (котлеты порционно, варенье на зиму, открытая упаковка с отсчётом срока).

Заморозка из заготовок дублируется в Инвентарь → Морозилку для удобства.

### Как добавить
Кнопка **[+]**, заполнить:
- Название (например «Свиные котлеты»)
- Количество и единица (5 кг)
- **Порций** — только для заморозки, опционально (помогает посчитать сколько обедов получится)
- Дата заморозки / заготовки / открытия (по умолчанию — сегодня)
- Хранить до / годен до — **подставляется автоматически из шеф-справочника!**

### ✨ Шеф-справочник (магия для Морозилки)
Когда вводишь название — внизу появляется зелёная подсказка:
> «Шеф советует: котлет — 120 дн.»

Дата «Хранить до» автоматически заполняется = сегодня + 120 дней.
**Если ты сама поменяешь дату** — подсказка не сотрёт твоё значение, появится кнопка «применить» если передумаешь.

### Что в справочнике (~90 продуктов)
- **Мясо**: говядина (12 мес), свинина (8 мес), баранина (9 мес), кролик (9 мес)
- **Фарш и котлеты сырые** (4 мес), пельмени (4 мес), вареники (3 мес), голубцы (3 мес)
- **Птица**: курица/индейка (9 мес), утка/гусь (6 мес)
- **Рыба**: треска/минтай (6 мес — нежирная), лосось/форель/скумбрия (3 мес — жирная), креветки (4 мес)
- **Готовые блюда**: плов/рагу/борщ (3 мес), бульон (4 мес)
- **Тесто**: дрожжевое (3 мес), слоёное (6 мес), песочное (4 мес)
- **Хлеб** (3 мес), блины (2 мес)
- **Овощи** (бланшированные): брокколи/горошек/кукуруза (12 мес), перец/кабачки (8 мес)
- **Ягоды**: клубника/малина/смородина/черника (12 мес)
- **Зелень**: укроп/петрушка (6 мес)
- **Молочка**: масло сливочное (9 мес), сыр твёрдый (6 мес), творог (2 мес)
- **Колбасные**: сосиски/колбаса (2 мес), бекон (1 мес), сало солёное (6 мес)

### Карточка заготовки
- Название и количество (для заморозки + порций)
- «заморозили 23 мая 2026 г.» / «заготовлено» / «открыто»
- «до 20 сент.» (или «истекает через 5 дн.» / «просрочен»)
- Кнопка корзины

### Алерт «Скоро истекает»
В каждой вкладке сверху — заготовки со сроком ≤ 3 дней.

## 🧾 8. Чеки

Раздел `/receipts`. Записывает всё что покупаешь, для аналитики и отслеживания цен.

### Как добавить чек
1. Кнопка **«Сфотографировать чек»** или **«+ Создать вручную»**.
2. Сфоткай чек ровно, при хорошем освещении.
3. Google Gemini Vision (AI) распознает текст и извлечёт:
   - Название магазина (Aldi, Albert Heijn, Jumbo...)
   - Дата покупки
   - Все позиции с названиями и ценами
   - Итог чека
4. Если магазин или дата не распозналась — кликни на пустое место, появится поле ввода (можно вписать вручную).

### Страница чека
- Шапка: магазин, дата, итог, валюта.
  - Магазин и дата редактируются по клику ✏️
- Список позиций. Каждую можно:
  - Редактировать (название, количество, цена)
  - Удалить
  - Добавить новую вручную
- Кнопка **«Перепарсить»** — если улучшили парсер, пересобирает позиции из сохранённого OCR-текста (без повторного запроса в Gemini).
- Кнопка **«Показать сырой текст»** — что увидел Gemini.
- Кнопка **«Удалить чек»**.

### Product Master — точные цены ALDI
Когда сохраняешь чек, цены товаров записываются в каталог.
При следующем чеке ALDI (формат «все имена сверху, все цены снизу») система использует эти цены для точной привязки. Чем больше чеков — тем точнее работает.

### Поддерживаемые валюты
EUR (по умолчанию) и RUB. Меняется в Настройках.

## 🍳 9. Что приготовить?

Раздел `/what-to-cook`. Подбор рецептов на основе того что есть дома.

### Как работает
1. Берёт твой инвентарь (что есть в холодильнике / морозилке / кладовой)
2. Перебирает все рецепты
3. Считает сколько ингредиентов уже есть, сколько докупить
4. Сортирует: сначала рецепты где почти всё есть

### Карточка рецепта в результатах
- «У тебя есть 5 из 7 ингредиентов»
- Список «Не хватает: молоко, петрушка»
- Кнопка «Готовить» / «Подробнее»

## 🔧 15. Технические моменты

### Render Free Plan
Сервер спит каждые 15 минут бездействия. При первом заходе после паузы:
- Появится сообщение «Сервер просыпается»
- Подожди 30 секунд

### Manual Deploy на Render
После каждого merge на GitHub нужно вручную запустить деплой:
1. https://dashboard.render.com/
2. Выбрать сервис **chefdom**
3. Кнопка **«Manual Deploy»** → **«Deploy latest commit»**
4. Подождать 2–3 минуты

### Безопасность
- PIN хранится в виде bcrypt-хеша (защищён от чтения даже если базу украдут)
- Сессии — Bearer-токен 32 байта, действительны 30 дней
- Защита от брутфорса: 5 неверных попыток → блок IP на 30 минут
- API защищено — без сессии нельзя ничего ни читать, ни писать

## ❓ 16. Что делать если что-то не работает

### «Сервер не отвечает» / страница долго грузится
- Скорее всего сервер на Render заснул.
- Подожди 30 секунд — он проснётся.

### Чек распознался плохо
1. Открой чек, нажми «Показать сырой текст» — увидишь что увидел Gemini.
2. Если текста почти нет — фото плохое, сфоткай заново ровно при хорошем освещении.
3. Если текст есть, но позиции неверные — нажми «Перепарсить».
4. Если совсем ничего — отредактируй вручную.

### Ингредиенты не объединяются в покупках
- Должны автоматически. Если дубли — открой страницу Покупки, авто-дедупликация удалит при загрузке.

### «У меня нет PIN»
PIN по умолчанию: **1234** (если не менялся).

### Не получается войти после нескольких попыток
Защита от брутфорса — заблокирован твой IP на 30 минут.
Подожди или зайди с другого устройства.

### Шеф-справочник не подсказал срок
- Работает только во вкладке «Заморозка»
- Нужно ввести минимум 3 символа
- Подсказка ищет по подстроке: «свинина» → найдётся, «свин» → найдётся, «свн» → нет.
- Если в справочнике нет твоего продукта — впиши срок руками. Можешь предложить добавить ключ — это правится в коде.

### «Хочу удалить все данные и начать заново»
Settings → Импорт бэкапа → загрузить пустой JSON.
Или связаться с разработчиком для очистки базы.
