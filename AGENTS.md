# ChefDom

Система управления домашней кухней.

## Основные модули

- Product Master (единая база продуктов)
- Inventory (холодильник, морозилка, кладовая)
- Recipes (рецепты)
- Weekly Menu (меню недели)
- Shopping List (список покупок)
- Receipt OCR (сканирование чеков)
- Barcode Scanner (сканирование штрих-кодов)

## Технологии

- React
- TypeScript
- Node.js
- GitHub
- Render

## Правила проекта

- Не удалять существующий функционал без необходимости.
- Использовать существующие компоненты перед созданием новых.
- Не менять структуру базы данных без миграции.
- Сохранять совместимость со старыми данными.
- Предпочитать небольшие изменения вместо полной переработки модулей.

## Цель проекта

Домашняя система управления кухней с автоматическим учетом продуктов, рецептами, меню недели и генерацией списка покупок.
